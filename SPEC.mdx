# Loca Jett Oficial — Especificação da Plataforma

> **Locação de Jet Skis em Goiás · Sua próxima experiência começa na água.**
> Projeto **exclusivamente náutico**: nada de motos, carros ou veículos terrestres.

Este documento descreve a plataforma implementada neste repositório (frontend React + Vite, publicado na Vercel) e o que falta para levá-la à produção com backend real.

## 1. Engenharia reversa da referência

Referência analisada: página de listagem "Aluguel de Jet Ski em Goiânia" (diretório MyLinQ). É uma página de diretório simples: título, nome da empresa, chamada para orçamento, telefone, endereço, região/categoria e um formulário de dúvidas.

| Elemento da referência | Como foi transformado |
|---|---|
| Título "Aluguel de Jet Ski em…" (SEO local) | H1 cinematográfico + SEO "aluguel de Jet Ski em Goiás" no `<head>` e schema `LocalBusiness` |
| "Solicite um orçamento online" | Barra de busca de disponibilidade + fluxo de reserva completo |
| Telefone / WhatsApp | Botão flutuante de WhatsApp + finalização da reserva pelo WhatsApp |
| Endereço / Região | Página **Locais** com mapa esquemático de Goiás por regiões |
| Formulário "Perguntas e Dúvidas" | Página **Contato** com validação, enviando pelo WhatsApp |
| Visual de diretório genérico | Identidade premium: oceano noturno + pôr do sol, vidro fosco, gradientes ciano/azul |

Os dados reais da empresa da referência **não** foram copiados.

## 6. Componentes

- **Navbar** — logo, links, `🛒 Minha Reserva` com contador (Jet Ski + serviços + experiência paga), Login/Minha conta, hamburger no mobile.
- **Mini carrinho** — gaveta lateral com Jet Ski, duração, adicionais, cupom, total, caução e botão **VER MINHA RESERVA**.
- **Hero** — céu noturno → pôr do sol, sol animado, 3 camadas de ondas em loop, Jet Ski ilustrado flutuando. CTAs "Reservar agora" e "Ver Jet Skis". Barra de busca (data, duração, pessoas, local) sobreposta.
- **Card de Jet Ski** — imagem, status, marca/modelo, capacidade, potência, velocidade, preço/hora, **Ver detalhes** e **Reservar**.
- **Calendário** — estados Disponível · Reservado · Em uso · Manutenção · Indisponível; só permite clicar em dias com horários livres.
- **Slots de horário** — calculados por `slotsFor(jetId, data, duração)`, que remove qualquer intervalo sobreposto a outra reserva não cancelada.

## 7. Fluxo do cliente

```text
Entrar no site → Ver Jet Skis → Escolher Jet Ski → Data → Horário → Duração → Experiências/serviços
→ Dados pessoais → 🛒 Minha Reserva → Resumo → Finalizar → WhatsApp → Atendimento Loca Jett
```

**Minha Reserva** (`/minha-reserva`) em 6 etapas: 1. Jet Ski · 2. Data e horário · 3. Experiência · 4. Dados pessoais · 5. Resumo · 6. Finalização. Não é possível avançar sem data/horário válidos e dados válidos.

**Validações:** nome e sobrenome, CPF (dígitos verificadores), telefone (10–11 dígitos), e-mail, data de nascimento (titular ≥ 18 anos), cidade, estado e aceite dos termos/LGPD. Máscaras para CPF, telefone e CEP.

**Preço:** 1h/2h/3h = preço/hora × horas · 4h = preço de meio período · 8h = diária. Total = Jet Ski + adicionais − cupom + taxa fixa. Caução exibida à parte (devolvível).

## 8. Finalização pelo WhatsApp

Ao clicar em **Finalizar Reserva pelo WhatsApp**:
1. valida os dados → 2. verifica disponibilidade novamente → 3. salva reserva e cliente → 4. gera número `LJ-XXXXXX` (6 caracteres sem ambíguos, único) → 5. calcula total → 6. monta a mensagem → 7. abre `https://wa.me/<numero>?text=<mensagem codificada>` (funciona no WhatsApp Web e no app).

- Número da empresa: `settings.whatsapp` (painel › Configurações) ou `SITE.whatsapp` em `src/config.js`. **Nunca fixo no código de negócio.** Sem número configurado, o WhatsApp abre para o usuário escolher o contato.
- **CPF e endereço não são enviados** pelo WhatsApp (LGPD).
- Status inicial: **Aguardando atendimento** → Aguardando confirmação → Confirmada → Pagamento pendente → Pagamento confirmado → Em andamento → Concluída / Cancelada.

## 10. Painel administrativo
Login com perfis **Proprietário** (tudo), **Gerente**, **Atendente** e **Operacional** (permissões por módulo em `ROLES`, `src/store.js`). Demonstração: `admin@locajett.com / admin123` — **troque em Usuários antes de usar**.

- **Dashboard:** faturamento hoje/semana/mês/ano, reservas hoje/pendentes/confirmadas, ticket médio, Jet Skis disponíveis/reservados/manutenção, clientes; gráficos de faturamento 7 dias, reservas por dia, horários mais procurados, Jet Skis mais reservados.
- **Reservas:** filtros, confirmar, cancelar, iniciar, concluir (+pontos), alterar data/horário/Jet Ski com checagem de conflito, gerar contrato, abrir WhatsApp do cliente; lista de **reservas abandonadas** com lembrete + cupom.
- **Jet Skis, Clientes, Locações, Manutenção (com alertas), Pagamentos, Financeiro (rentabilidade e ranking), Contratos, Cupons, Fidelidade, Indicações, Avaliações (responder/ocultar), Relatórios (CSV), Notificações, Usuários, Configurações (WhatsApp, horário, taxa, locais, experiências, serviços, limpar dados de exemplo).**

services(id, nome, descricao, imagem, preco, ativo)          experiences(id, nome, descricao, icon, preco, ativo)
reservations(id 'LJ-XXXXXX' PK, client_id FK, jet_ski_id FK, location_id FK, experience_id FK, data, hora_inicio, duracao_h, pessoas, subtotal, adicionais, desconto, taxas, caucao, total, coupon_id FK NULL, status ENUM, pagamento ENUM, obs, created_at)
reservation_services(reservation_id FK, service_id FK, preco)   -- N:N

**Integridade de agenda:** no PostgreSQL use `EXCLUDE USING gist (jet_ski_id WITH =, tsrange(inicio, fim) WITH &&) WHERE (status <> 'cancelada')` para impossibilitar reservas sobrepostas mesmo com acessos simultâneos.

## 12. Segurança e LGPD
Autenticação com senha `bcrypt/argon2` (o protótipo usa SHA-256 apenas localmente), sessões `httpOnly` + `SameSite`, autorização por papel em **cada rota da API**, validação no servidor (zod), queries parametrizadas (SQL Injection), escape de saída (React já evita XSS), rate limiting em login e criação de reservas, `robots.txt` bloqueando `/admin` e `/cliente`, consentimento LGPD, mínimo de dados no WhatsApp.

## 13. SEO e performance
Title/description/keywords focados em "aluguel de Jet Ski em Goiás", Open Graph, schema `LocalBusiness`, `sitemap.xml`, `robots.txt`, URLs amigáveis. Ilustrações em SVG (leves); ao usar fotos reais, servir WebP/AVIF com `loading="lazy"`. Code splitting por rota recomendado quando o admin crescer.

---

## 14. Próxima fase — backend
Recomendado: **Next.js (App Router) + PostgreSQL (Neon/Supabase) + Prisma**, ou Vercel Functions + Postgres. Trocar `getDB/setDB/upsert` em `src/store.js` por chamadas `fetch('/api/...')`. Endpoints: `GET /api/jet-skis`, `GET /api/availability?jet=&date=&dur=`, `POST /api/reservations`, `PATCH /api/reservations/:id`, `POST /api/auth/*`, CRUD admin.

## 15. Pagamentos
Preparado para PIX (Mercado Pago / Asaas / Efí), cartão e pagamento online, com **sinal**, **caução** e **restante** como registros separados em `payments`, webhook atualizando o status da reserva.

## 16. Contrato digital
Após confirmação: gerar contrato com dados do cliente, Jet Ski, período e valores → exibir termos → assinatura (aceite + data/hora + IP, ou integração ZapSign/Clicksign) → armazenar → gerar PDF.
